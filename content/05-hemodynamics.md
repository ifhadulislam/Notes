# Hemodynamic Disorders, Thrombosis & Shock

## Edema

- Accumulation of ==excess fluid in interstitial tissue or body cavities==.
- Generalized severe edema = ==anasarca==. In cavities : hydrothorax, hydropericardium, ==hydroperitoneum (ascites)==.

### Pathophysiologic categories :

| Mechanism | Causes |
|---|---|
| ==↑ Hydrostatic pressure== | Impaired venous return : ==CHF==, constrictive pericarditis, ==ascites in cirrhosis==, venous obstruction (DVT), external pressure; arteriolar dilation (heat) |
| ==↓ Plasma oncotic pressure (hypoproteinemia)== | ==Nephrotic syndrome== (most common), ==cirrhosis==, ==protein malnutrition (kwashiorkor)==, protein-losing gastroenteropathy |
| ==Lymphatic obstruction== | Inflammatory (==filariasis== → elephantiasis), neoplastic, post-surgical (==axillary dissection → arm edema==), post-irradiation; ==peau d'orange== in breast cancer |
| ==Sodium retention== | Excessive salt intake with renal insufficiency, ==↑ renin–angiotensin–aldosterone (CHF)==, acute GN |
| Inflammation | Acute & chronic inflammation, angiogenesis (exudate) |

:::pearl
- ==Renal edema (nephrotic)== : generalized, first appears in ==loose connective tissue — periorbital (eyelids)==, morning.
- ==Cardiac edema== : ==dependent== (legs in standing, sacrum in recumbent).
- ==Pulmonary edema== : ==left ventricular failure== (most common) — heavy wet lungs (2–3× normal), ==frothy, blood-tinged fluid== on cut section.
- ==Brain edema== : ==flattened gyri, narrowed sulci, compressed ventricles== → herniation.
- ==Pitting edema== — interstitial fluid; non-pitting — lymphedema, myxedema.
:::

## Hyperemia & Congestion

| Feature | Hyperemia (active) | Congestion (passive) |
|---|---|---|
| Mechanism | ==Arteriolar dilation== → ↑ inflow | ==Impaired venous outflow== |
| Colour | ==Red (erythema)== — oxygenated blood | ==Blue-red (cyanosis)== — deoxygenated |
| Examples | Exercise, inflammation, blushing | CHF (systemic), venous obstruction (local) |

### Chronic venous congestion (CVC) — organs :

| Organ | Cause | Morphology |
|---|---|---|
| ==Lung== | ==Left heart failure==, mitral stenosis | Acute : engorged alveolar capillaries, septal edema. Chronic : thick fibrotic septa, ==hemosiderin-laden macrophages ("heart failure cells")== in alveoli → ==brown induration of lung== |
| ==Liver== | ==Right heart failure==, (Budd–Chiari) | ==Nutmeg liver== : congested red-brown ==centrilobular areas== (zone 3) alternating with pale/fatty periportal areas. Centrilobular hemorrhagic necrosis; ==cardiac sclerosis / cardiac cirrhosis== (long-standing) |
| ==Spleen== | Right heart failure, ==portal hypertension== | ==Congestive splenomegaly== (up to 500–1000 g), firm; ==Gamna–Gandy bodies== (siderofibrotic nodules — hemosiderin + calcium on collagen) |
| Kidney | Right heart failure | Enlarged, cyanotic; medulla congested |

:::green
- ==Heart failure cells== — demonstrated with ==Perls Prussian blue== (hemosiderin, blue).
- Zone 3 necrosis : congestion (RHF), ==shock==, ==acetaminophen==, ==CCl₄==, alcohol, halothane. Zone 1 : ==phosphorus poisoning==, eclampsia (periportal fibrin). Zone 2 : ==yellow fever==.
:::

## Hemorrhage

| Term | Size / site |
|---|---|
| ==Petechiae== | ==1–2 mm== — ↑ capillary pressure, ==thrombocytopenia==, platelet dysfunction |
| ==Purpura== | ==≥ 3 mm (up to 1 cm)== — trauma, vasculitis, vascular fragility |
| ==Ecchymoses (bruise)== | ==> 1–2 cm== subcutaneous hematomas; colour changes : red-blue (Hb) → ==blue-green (bilirubin)== → ==golden-brown (hemosiderin)== |
| Hematoma | Blood accumulation within tissue |
| Hemothorax, hemopericardium, hemoperitoneum, hemarthrosis | Blood in cavities |

- Clinical significance : volume (> 20% rapid loss → ==hemorrhagic shock==), site (intracranial), chronic → ==iron deficiency anemia==.

## Hemostasis — Normal

:::flow
Arteriolar ==vasoconstriction== (reflex + ==endothelin==)
==Primary hemostasis== : platelet adhesion (==vWF–GpIb==) → shape change, granule release (ADP, TXA₂) → aggregation (==GpIIb/IIIa – fibrinogen==) → ==platelet plug==
==Secondary hemostasis== : ==tissue factor (factor III)== → coagulation cascade → ==thrombin== → fibrin
Clot stabilization & resorption : fibrin polymerization (==factor XIIIa==), platelet contraction; ==t-PA → plasmin== limits clot
:::

### Endothelium — anti- vs pro-thrombotic :

| Antithrombotic (normal) | Prothrombotic (injured / activated) |
|---|---|
| ==PGI₂, NO== (inhibit platelets); ==ADPase (CD39)== | ==vWF== (platelet adhesion) |
| ==Thrombomodulin== → thrombin activates ==protein C== | ==Tissue factor== (induced by TNF, IL-1, LPS) |
| ==Heparin-like molecules== → ↑ antithrombin III | ==PAI-1== (↓ fibrinolysis) |
| ==TFPI== (tissue factor pathway inhibitor) | |
| ==t-PA== (fibrinolysis) | |

### Platelets :

- ==α-granules== : ==fibrinogen, fibronectin, factor V, vWF, PF4, PDGF, TGF-β, P-selectin==.
- ==Dense (δ) granules== : ==ADP, ATP, Ca²⁺, serotonin, histamine, epinephrine==.
- Disorders : ==Bernard–Soulier (GpIb)== — giant platelets, no ristocetin aggregation; ==Glanzmann thrombasthenia (GpIIb/IIIa)== — no aggregation with ADP, normal ristocetin.

### Coagulation cascade :

:::flow
Extrinsic : ==tissue factor + VIIa== (PT) || Intrinsic : ==XII → XI → IX (+VIIIa)== (aPTT)
Common pathway : ==X → Xa (+Va, Ca²⁺, phospholipid) — prothrombinase==
Prothrombin (II) → ==thrombin (IIa)==
Fibrinogen → fibrin monomer → ==cross-linked fibrin (XIIIa)==
:::

- ==Vitamin K-dependent factors== : ==II, VII, IX, X, protein C, protein S== (γ-carboxylation of glutamate). Shortest half-life : ==factor VII (~6 h)== → PT prolongs first with warfarin.
- Thrombin : most important — converts fibrinogen, activates V, VIII, XI, XIII, platelets (PAR receptors); with thrombomodulin activates protein C.
- ==Natural anticoagulants== : ==antithrombin III== (inhibits IIa, IXa, Xa, XIa, XIIa; ↑ by heparin), ==protein C + S== (inactivate ==Va and VIIIa==), TFPI.

## Thrombosis

### Virchow's triad :

1. ==Endothelial injury== — most important; dominant in heart and arterial circulation (MI, ulcerated plaque, vasculitis, hypertension, toxins of smoking)
2. ==Abnormal blood flow (stasis or turbulence)== — stasis : venous thrombi; turbulence : arterial and cardiac thrombi
3. ==Hypercoagulability (thrombophilia)==

### Hypercoagulable states :

Primary (genetic) :

1. ==Factor V Leiden== (Arg506Gln; ==resistance to activated protein C==) — ==most common inherited cause==
2. ==Prothrombin G20210A mutation== (↑ prothrombin) — second most common
3. Deficiency of ==antithrombin III== (heparin resistance), ==protein C==, ==protein S==
4. ↑ factor VIII, IX, XI, fibrinogen
5. ==Hyperhomocysteinemia== (MTHFR — also acquired : folate / B12 / B6 deficiency)

Secondary (acquired) :

1. ==Prolonged bed rest / immobilization==, surgery, fractures, burns
2. ==Malignancy== (==Trousseau syndrome== — migratory thrombophlebitis; ==mucin-secreting adenocarcinomas — pancreas==)
3. ==Antiphospholipid antibody syndrome==
4. ==Heparin-induced thrombocytopenia (HIT)== — ==antibodies to heparin–PF4 complex==, day 5–14
5. Pregnancy & postpartum, ==oral contraceptives==, estrogen therapy
6. ==Nephrotic syndrome== (loss of antithrombin III)
7. Myeloproliferative neoplasms (==polycythemia vera, JAK2==), PNH, sickle cell
8. Smoking, obesity, cardiomyopathy, atrial fibrillation, prosthetic valves, DIC

:::green Antiphospholipid syndrome
- Antibodies : ==lupus anticoagulant==, ==anticardiolipin==, ==anti-β2-glycoprotein I==.
- ==In vitro : prolonged aPTT (paradoxically) ; in vivo : thrombosis==.
- Features : recurrent arterial/venous thrombosis, ==recurrent miscarriages==, thrombocytopenia, ==false-positive VDRL==, livedo reticularis.
- ==Catastrophic APS== — multiorgan microvascular thrombosis.
- Treatment : lifelong ==warfarin== (not DOACs in triple-positive).
:::

### Morphology of thrombi :

- ==Lines of Zahn== — alternating ==pale layers of platelets + fibrin== and ==dark layers of RBCs== — indicate ==thrombosis in flowing blood (antemortem)==.

| Feature | ==Antemortem thrombus== | Postmortem clot |
|---|---|---|
| Lines of Zahn | ==Present== | Absent |
| Attachment | ==Firmly attached== to vessel wall | Not attached; gelatinous |
| Appearance | Dry, granular, friable, grey-red | Rubbery, ==dark red "currant jelly"== dependent portion + ==yellow "chicken fat"== supernatant |
| Shape | Shape of vessel ± tail | Cast of vessel |

| Type | Features |
|---|---|
| ==Arterial / cardiac (mural)== | Endothelial injury/turbulence; begin at injury; grow ==retrograde==; ==white / pale (platelet-rich)==; occlusive in coronary, cerebral, femoral arteries |
| ==Venous (phlebothrombosis)== | ==Stasis==; grow ==in direction of flow (toward heart)==; ==red / stasis thrombi (RBC-rich)==; ==deep veins of leg (90%)== |
| ==Vegetations== | Thrombi on heart valves — ==infective endocarditis, NBTE (marantic), Libman–Sacks (SLE)== |

### Fate of thrombus :

1. ==Propagation== — accumulates more platelets, fibrin → obstruction
2. ==Embolization== — dislodges, travels
3. ==Dissolution== — fibrinolysis (recent thrombi)
4. ==Organization and recanalization== — ingrowth of endothelial cells, SMC, fibroblasts; new capillary channels
5. Septic infection → ==mycotic aneurysm==

:::pearl
- ==Most common site of DVT== : ==deep veins of calf==; ==most significant (embolism)== : ==popliteal, femoral, iliac veins== (above knee).
- ==Superficial thrombophlebitis== (saphenous varicosities) rarely embolize.
- ==Phlegmasia alba dolens (milk leg)== — iliofemoral thrombosis in pregnancy.
:::

## Disseminated Intravascular Coagulation (DIC)

- ==Consumption coagulopathy== : widespread microvascular thrombi → consumption of platelets and factors → ==bleeding==.

Causes :

1. ==Obstetric complications== — ==abruptio placentae==, retained dead fetus, ==amniotic fluid embolism==, septic abortion, eclampsia
2. ==Infections== — ==Gram-negative sepsis== (most common), meningococcemia, malaria, Rocky Mountain spotted fever
3. ==Neoplasms== — ==acute promyelocytic leukemia (M3)==, adenocarcinomas (pancreas, prostate, lung)
4. Massive tissue injury — trauma, burns, extensive surgery
5. Others — snake bite, acute intravascular hemolysis, shock, giant hemangioma (Kasabach–Merritt), heat stroke

:::flow
Release of ==tissue factor== (placenta, tumour, APL granules) || ==Endothelial injury== (sepsis, LPS, TNF)
Widespread thrombin generation → microthrombi (fibrin) in small vessels
Consumption of platelets, fibrinogen, V, VIII → bleeding || Microangiopathic hemolytic anemia (==schistocytes==), ischemic organ damage
Secondary fibrinolysis → ==↑ D-dimer, FDPs== (most specific : ==D-dimer==)
:::

- Lab : ↓ platelets, ==↑ PT and aPTT==, ↓ fibrinogen, ↑ D-dimer, schistocytes.
- Organs : kidney (cortical necrosis), adrenal (==Waterhouse–Friderichsen== in meningococcemia), pituitary (==Sheehan==), brain, lungs.

## Embolism

- Detached intravascular solid, liquid or gaseous mass carried by blood to a distant site. ==99% from thrombi (thromboembolism)==.

### Pulmonary thromboembolism :

1. Source : ==95% from deep leg veins (above knee)==
2. ==60–80% clinically silent== (small)
3. Occluding > 60% of pulmonary circulation → ==sudden death, acute right heart failure (cor pulmonale)==, cardiovascular collapse
4. ==Saddle embolus== — at bifurcation of main pulmonary artery
5. Small-medium artery obstruction → ==hemorrhage (bronchial circulation intact)==; ==infarction only when circulation compromised (LVF)==
6. ==Paradoxical embolism== — venous embolus via ==ASD / PFO== into systemic circulation
7. Multiple emboli over time → ==pulmonary hypertension==

### Systemic thromboembolism :

- ==80% from intracardiac mural thrombi== (2/3 due to ==LV wall infarcts==, 1/4 ==left atrial dilation + atrial fibrillation==).
- Sites : ==lower extremities (75%)==, brain (10%), intestines, kidneys, spleen.

### Other emboli :

| Type | Key features |
|---|---|
| ==Fat & marrow embolism== | ==Long bone fractures (tibia, femur)==, burns, CPR; syndrome after ==1–3 days== : pulmonary insufficiency, neurologic symptoms, anemia, thrombocytopenia, ==petechial rash (upper body, axilla)==; ==Oil Red O / Sudan stain== on frozen section; fatal in ~10% |
| ==Air embolism== | > ==100 cc== needed for clinical effect; obstetric procedures, chest wall injury, IV lines. ==Decompression sickness (caisson disease)== — nitrogen bubbles : ==bends== (joints), ==chokes== (lungs); chronic : ==aseptic necrosis of femoral head, tibia, humerus== |
| ==Amniotic fluid embolism== | ==Mortality ~80%==; sudden dyspnea, cyanosis, shock, seizures, coma, ==DIC==; ==fetal squamous cells, lanugo hair, fat (vernix), mucin== in maternal pulmonary microcirculation |
| Tumour, bone marrow, atheromatous (cholesterol), foreign body (talc), septic | Atheroembolism : ==cholesterol clefts==, after angiography; ==livedo reticularis==, renal failure, eosinophilia |

## Infarction

- Area of ==ischemic necrosis== caused by occlusion of either arterial supply or venous drainage. ==99% due to thrombotic or embolic events==.

| Feature | ==Red (hemorrhagic) infarct== | ==White (anemic / pale) infarct== |
|---|---|---|
| Circulation | Venous occlusion; ==dual blood supply==; loose tissues; previously congested tissue; reperfusion | ==Arterial occlusion== in solid organs with ==end-arterial circulation== |
| Examples | ==Lung, small intestine==, ovarian torsion, testicular torsion, ==liver (dual)==, brain (embolic, reperfusion) | ==Heart, spleen, kidney== |
| Shape | ==Wedge-shaped== with occluded vessel at apex, periphery as base |
| Histology | ==Coagulative necrosis== (except brain : ==liquefactive==) | Coagulative necrosis |

### Factors affecting development of infarct :

1. ==Anatomy of vascular supply== — dual (lung, liver) or parallel (radial + ulnar artery) supply protects; end-arteries (kidney, spleen) do not
2. ==Rate of occlusion== — slow occlusion allows collaterals (coronary)
3. ==Tissue vulnerability to hypoxia== — neurons (3–4 min) > myocardium (20–30 min) > fibroblasts
4. ==Oxygen content of blood== — anemia, cyanosis, CHF worsen

- ==Septic infarction== → abscess (infected emboli from IE).
- Earliest histologic change in infarct : none in 4–12 h; ==acute inflammation at margins within hours to 1–2 days==.

## Gangrene

| Feature | ==Dry gangrene== | ==Wet gangrene== | Gas gangrene |
|---|---|---|---|
| Mechanism | ==Arterial occlusion==, slow | ==Venous + arterial occlusion==, infection (putrefaction) | ==Clostridium perfringens== (α-toxin, lecithinase) |
| Site | ==Limbs (toes)== | ==Bowel (strangulated hernia, volvulus)==, ==diabetic foot==, lung | Contaminated deep wounds, muscle (myonecrosis) |
| Line of demarcation | ==Clear== | Poorly defined | Absent |
| Appearance | Dry, shrunken, black (==iron sulfide== from Hb) | Moist, swollen, foul-smelling | Crepitus, gas bubbles |
| Spread | Slow | Rapid | Very rapid |
| Prognosis | Good | Poor (septicemia) | Poor |

- Examples : ==Fournier gangrene== (scrotum/perineum — synergistic), ==noma (cancrum oris)== (malnourished children), ==Meleney's== synergistic gangrene.

## Shock

- State of ==cellular hypoperfusion== due to ↓ cardiac output or ↓ effective circulating blood volume → ==impaired tissue perfusion and hypoxia==.

| Type | Mechanism | Examples |
|---|---|---|
| ==Cardiogenic== | ==Myocardial pump failure== | MI, arrhythmias, ==cardiac tamponade==, pulmonary embolism (obstructive) |
| ==Hypovolemic== | Inadequate blood or plasma volume | ==Hemorrhage, burns==, vomiting, diarrhea |
| ==Septic (distributive)== | ==Peripheral vasodilation + pooling==, endothelial activation/injury, DIC | ==Gram-negative > Gram-positive== sepsis, fungi |
| Neurogenic | Loss of vascular tone | Spinal cord injury, anesthetic accident |
| Anaphylactic | IgE-mediated systemic vasodilation, ↑ permeability | Drugs, insect stings, foods |

### Pathogenesis of septic shock :

1. ==Inflammatory mediators== — PAMPs (LPS) → TLRs → ==TNF, IL-1, IL-6, IFN-γ==, HMGB1; complement C3a, C5a
2. ==Endothelial activation and injury== — capillary leak, edema, ==↑ tissue factor== → DIC
3. ==Immune suppression== — CARS (compensatory anti-inflammatory response) — IL-10, lymphocyte apoptosis
4. ==Metabolic abnormalities== — ==insulin resistance, hyperglycemia==; ==relative adrenal insufficiency==
5. ==Organ dysfunction== — ARDS, AKI, liver, heart (↓ contractility)

### Stages of shock :

:::flow
==Nonprogressive (compensated)== : ↑ sympathetic (tachycardia, peripheral vasoconstriction, cool skin), RAAS, ADH — vital organ perfusion maintained
==Progressive== : tissue hypoperfusion → anaerobic glycolysis → ==lactic acidosis== → arteriolar dilation, blood pooling; DIC, ARDS
==Irreversible== : lysosomal enzyme leakage, myocardial depression, ==ischemic bowel → bacteremia==; ==ATN== — death
:::

### Morphology of shock :

| Organ | Change |
|---|---|
| ==Brain== | ==Ischemic encephalopathy== — watershed infarcts |
| ==Heart== | ==Subendocardial hemorrhage, necrosis, contraction band necrosis== |
| ==Kidney== | ==Acute tubular necrosis== (most common cause of oliguria) |
| ==Lung== | Relatively resistant in hypovolemic shock; ==DAD (shock lung, ARDS)== in septic shock — ==hyaline membranes== |
| Adrenal | ==Lipid depletion== of cortical cells (stress); ==Waterhouse–Friderichsen== hemorrhage |
| GIT | ==Patchy mucosal hemorrhages, necrosis (hemorrhagic enteropathy)== |
| Liver | ==Fatty change, central (zone 3) hemorrhagic necrosis== |

:::green Warm vs cold shock
- ==Septic shock — early "warm" shock==: vasodilation, warm flushed skin, ↑ cardiac output.
- Cardiogenic / hypovolemic — "cold" shock : cool clammy skin, ↓ CO, ↑ SVR.
- ==qSOFA== : RR ≥ 22, altered mentation, SBP ≤ 100. Septic shock = vasopressors to keep ==MAP ≥ 65== + ==lactate > 2 mmol/L== despite fluids.
:::

## Fluid & Electrolyte Derangements

| Disorder | Key causes | Key features |
|---|---|---|
| ==Hyponatremia== (< 135) | ==SIADH== (small cell lung Ca, CNS, drugs), CHF, cirrhosis, diuretics, Addison | ==Cerebral edema==, seizures; too-rapid correction → ==osmotic demyelination (central pontine myelinolysis)== |
| Hypernatremia (> 145) | Water loss, ==diabetes insipidus== | Brain shrinkage, hemorrhage |
| ==Hypokalemia== | Diuretics, vomiting, ==hyperaldosteronism==, insulin, β-agonists | ==U waves==, flat T, muscle weakness, ileus |
| ==Hyperkalemia== | Renal failure, ==Addison==, ACEi, tissue lysis, acidosis | ==Peaked T waves==, wide QRS, arrhythmia |
| Hypocalcemia | Hypoparathyroidism, CKD, vitamin D deficiency, pancreatitis | ==Tetany (Chvostek, Trousseau)==, ==prolonged QT== |
| Hypercalcemia | ==Hyperparathyroidism, malignancy== | "==Stones, bones, groans, moans==", short QT |
| Metabolic acidosis (↑ AG) | ==MUDPILES== : methanol, uremia, DKA, paraldehyde, isoniazid/iron, lactic, ethylene glycol, salicylates | Kussmaul breathing |
| Metabolic alkalosis | Vomiting, diuretics, hyperaldosteronism | Hypokalemia |

:::
