# Immunopathology

## Organisation of the Immune System

| Feature | Innate immunity | Adaptive immunity |
|---|---|---|
| Specificity | Pathogen-associated molecular patterns (PAMPs) | Highly specific antigens |
| Memory | None (trained immunity limited) | ==Memory== |
| Cells | ==Neutrophils, macrophages, NK cells, dendritic cells, mast cells, ILCs== | ==T and B lymphocytes== |
| Molecules | Complement, ==TLRs==, antimicrobial peptides, cytokines (IFN-α/β) | ==Antibodies==, TCR, BCR |
| Speed | Minutes–hours | Days |

### Lymphocytes :

| Cell | Markers | Key functions |
|---|---|---|
| ==T cells== | ==CD3==, TCR (αβ — 95%; γδ — mucosal) | ==Cell-mediated immunity==; mature in ==thymus== |
| ==CD4+ helper T== | CD4, ==recognize antigen on MHC class II== | Help B cells, macrophages; ==CD4:CD8 = 2:1== |
| ==CD8+ cytotoxic T== | CD8, ==recognize MHC class I== | Kill virus-infected / tumour cells (==perforin, granzyme==, FasL) |
| ==Treg== | ==CD4, CD25 (IL-2Rα), FOXP3== | Suppress immunity (==IL-10, TGF-β, CTLA-4==); ==FOXP3 mutation → IPEX== |
| ==B cells== | ==CD19, CD20, CD21 (EBV receptor, CR2)==, surface IgM & IgD | Humoral immunity → ==plasma cells (CD138)== |
| ==NK cells== | ==CD16 (FcγRIII), CD56==; ==no TCR== | Kill cells lacking MHC-I ("missing self"); ==ADCC==; ==IL-12== activates; produce IFN-γ |
| ==Dendritic cells== | CD11c, ==MHC II== | ==Most potent antigen-presenting cells==; follicular DC (antigen display for B cells, CD21, CD35 — not APC proper) |

### CD4+ T helper subsets :

| Subset | Induced by | Signature cytokines | Functions / disease |
|---|---|---|---|
| ==Th1== | ==IL-12, IFN-γ== (T-bet) | ==IFN-γ==, IL-2 | Activate ==macrophages (M1)==, ==granulomas==, DTH; IgG opsonizing |
| ==Th2== | ==IL-4== (GATA-3) | ==IL-4, IL-5, IL-13== | ==IgE switching, eosinophils==, helminths, ==allergy, asthma==, M2 |
| ==Th17== | ==IL-1, IL-6, IL-23, TGF-β== (RORγt) | ==IL-17, IL-22== | ==Neutrophil recruitment==, extracellular bacteria & fungi; ==psoriasis, IBD, RA==; ↓ in hyper-IgE (STAT3) |
| Tfh | IL-6, IL-21 (Bcl-6) | IL-21, IL-4 | Germinal centre B-cell help |
| Treg | TGF-β, IL-2 (FOXP3) | IL-10, TGF-β | Tolerance |

### MHC (HLA) molecules — chromosome 6 :

| Feature | ==Class I== | ==Class II== |
|---|---|---|
| Loci | ==HLA-A, B, C== | ==HLA-DP, DQ, DR== |
| Distribution | ==All nucleated cells + platelets== (not RBCs) | ==APCs== (dendritic cells, macrophages, B cells), activated T cells, thymic epithelium |
| Structure | α chain + ==β2-microglobulin== | α + β chains |
| Antigen | ==Endogenous (cytosolic) — proteasome → TAP== | ==Exogenous — endocytosed, invariant chain== |
| Presents to | ==CD8+== T cells | ==CD4+== T cells |

- Class III region : complement (C2, C4, factor B), ==TNF==, HSP70.

### Immunoglobulins :

| Ig | Key features |
|---|---|
| ==IgG== | ==Most abundant in serum (75%)==; ==crosses placenta==; opsonization, complement (IgG3 > IgG1), ==secondary response==; 4 subclasses (==IgG4-related disease==) |
| ==IgA== | ==Most produced overall==; ==secretory IgA (dimer + J chain + secretory component)== in mucosa, colostrum; ==most common primary Ig deficiency== |
| ==IgM== | ==Pentamer==; ==first antibody in primary response==; ==best complement activator==; largest; B-cell receptor (monomer); isohemagglutinins |
| ==IgE== | Binds ==FcεRI on mast cells, basophils==; ==type I hypersensitivity==, helminths; ==lowest serum concentration==; heat labile |

## Hypersensitivity Reactions

| Type | Mechanism | Mediators | Examples |
|---|---|---|---|
| ==Type I (immediate / anaphylactic)== | ==IgE on mast cells== cross-linked by allergen; ==Th2== | Histamine, leukotrienes, PGD₂, cytokines | ==Anaphylaxis==, ==bronchial asthma (atopic)==, allergic rhinitis, urticaria, food allergy, ==Casoni test== |
| ==Type II (antibody-mediated / cytotoxic)== | ==IgG / IgM against fixed antigens on cells or ECM== | Complement (MAC), ==opsonization==, ADCC, ==receptor dysfunction== | ==AIHA==, ==transfusion reactions==, ==HDN (Rh)==, ==ITP==, ==Goodpasture==, ==Graves (stimulating)==, ==myasthenia gravis (blocking)==, pemphigus vulgaris, ==bullous pemphigoid==, ==acute rheumatic fever==, pernicious anemia, ==hyperacute rejection== |
| ==Type III (immune complex)== | ==Antigen–antibody complexes deposit in vessels== → complement activation → neutrophils | ==Complement (C3a, C5a)==, neutrophil enzymes | ==SLE==, ==post-streptococcal GN==, ==PAN==, ==serum sickness==, ==Arthus reaction==, reactive arthritis, ==HSP (IgA)==, cryoglobulinemia, ==hypersensitivity pneumonitis (III + IV)== |
| ==Type IV (T-cell / delayed)== | ==CD4+ (DTH — Th1/Th17)== and ==CD8+ (cytotoxicity)==; no antibodies | IFN-γ, IL-17, TNF; perforin/granzyme | ==Tuberculin (Mantoux) test==, ==contact dermatitis (poison ivy, nickel)==, ==type 1 DM, MS, RA, IBD==, Hashimoto, ==granulomas (TB)==, ==acute cellular graft rejection==, Lepromin test, ==patch test== |

:::mnemo Hypersensitivity — "ACID"
Type ==I : A==naphylactic / ==A==llergic · Type ==II : C==ytotoxic (antibody) · Type ==III : I==mmune complex · Type ==IV : D==elayed (cell-mediated). Antibody in I, II, III; ==no antibody in IV==.
:::

### Type I — phases :

:::flow
First exposure → ==Th2== → ==IL-4== → B cells switch to ==IgE== → binds ==FcεRI== on mast cells (==sensitization==)
Re-exposure : allergen cross-links IgE → ==mast cell degranulation==
==Immediate reaction (5–30 min)== : histamine, proteases, PGD₂, LTC₄ → vasodilation, leakage, bronchospasm || ==Late-phase reaction (2–24 h)== : eosinophils, neutrophils, Th2 cells → tissue damage (asthma)
:::

### Type III — systemic vs local :

- ==Serum sickness (systemic)== : ==5–10 days after foreign protein (horse anti-thymocyte globulin)== — fever, urticaria, arthralgia, ==proteinuria, lymphadenopathy, ↓ C3==.
- ==Arthus reaction (local)== : localized ==necrotizing vasculitis== at site of injection (hours) in previously immunized host — ==fibrinoid necrosis==; e.g. after tetanus booster.
- Lesions : ==fibrinoid necrosis== of vessels; ==immunofluorescence : granular deposits (lumpy-bumpy)== vs linear in anti-GBM (type II).

:::green
- ==Type V hypersensitivity== (some texts) : stimulatory antibodies — ==Graves disease (TSH receptor)== (classified under type II in Robbins).
- ==Type II drugs : penicillin-induced hemolysis (hapten), methyldopa (autoimmune), quinidine (immune complex/innocent bystander)==.
- ==Contact dermatitis is type IV== but is mediated by both CD4 and CD8 T cells; ==Langerhans cells== are the APCs.
- ==Jones–Mote reaction== (cutaneous basophil hypersensitivity) — variant of type IV.
:::

## Autoimmunity

### Mechanisms :

1. ==Failure of central tolerance== — ==AIRE mutation (thymic expression of tissue antigens) → APS-1 (APECED)==
2. ==Failure of peripheral tolerance== — anergy, ==Tregs (FOXP3 → IPEX)==, ==CTLA-4, PD-1==, deletion by apoptosis (==Fas/FasL → ALPS==)
3. ==Genetic susceptibility== — HLA, ==PTPN22== (most common non-HLA; RA, T1DM), ==NOD2== (Crohn), IL-23R
4. ==Infections== — ==molecular mimicry (rheumatic fever — streptococcal M protein)==; polyclonal B-cell activation (EBV); ==epitope spreading==
5. Tissue injury releasing sequestered antigens (==sympathetic ophthalmia==, post-vasectomy anti-sperm)
6. ==Female predominance== (hormones, X-chromosome genes)

## Systemic Lupus Erythematosus (SLE)

- Prototype ==multisystem autoimmune disease (type III > type II)==; ==F : M = 9 : 1==; reproductive age.
- ==Defective clearance of apoptotic bodies== (nuclear antigens) + ==type I interferon signature== + UV light, drugs.
- ==Libman–Sacks endocarditis== : small, sterile vegetations on ==both surfaces== of valve (mitral).
- ==LE cell== : neutrophil engulfing ==denatured nucleus (hematoxylin body)==.
- ==Onion-skin lesion of spleen== (periarterial fibrosis).

### Lupus nephritis (ISN/RPS classes) :

| Class | Features |
|---|---|
| I | Minimal mesangial |
| II | Mesangial proliferative |
| III | Focal (< 50% glomeruli) |
| ==IV== | ==Diffuse proliferative (≥ 50%)== — ==most common and most severe==; ==wire-loop lesions (subendothelial deposits)==, ==full-house immunofluorescence (IgG, IgA, IgM, C3, C1q)== |
| ==V== | ==Membranous== — nephrotic syndrome |
| VI | Advanced sclerosing (≥ 90%) |

:::mnemo SLE criteria (classic 11) — "SOAP BRAIN MD"
==S==erositis · ==O==ral ulcers · ==A==rthritis · ==P==hotosensitivity · ==B==lood disorders · ==R==enal disorder · ==A==NA · ==I==mmunologic (dsDNA, Sm, aPL) · ==N==eurologic (seizure, psychosis) · ==M==alar rash · ==D==iscoid rash. (EULAR/ACR 2019 : ANA ≥ 1:80 entry criterion.)
:::

## Transplant Rejection

| Type | Timing | Mechanism | Morphology |
|---|---|---|---|
| ==Hyperacute== | ==Minutes–hours== | ==Pre-formed antibodies== (ABO, anti-HLA from transfusions, pregnancy, previous transplant) — ==type II== | ==Thrombosis, fibrinoid necrosis, infarction==; cyanotic, mottled graft; prevented by cross-match |
| ==Acute cellular== | ==Weeks–months (usually < 6 months)== | ==CD8+ CTL and CD4+== (type IV) | ==Interstitial mononuclear infiltrate, tubulitis, endotheliitis (endarteritis)== |
| ==Acute antibody-mediated (humoral)== | Days–months | Donor-specific antibodies (DSA) | ==Vasculitis, glomerulitis, peritubular capillaritis, C4d deposition== in peritubular capillaries |
| ==Chronic== | ==Months–years== | T cells (IFN-γ) + antibodies | ==Arteriosclerosis (intimal thickening — graft vasculopathy)==, interstitial fibrosis, tubular atrophy; ==transplant glomerulopathy==; ==bronchiolitis obliterans (lung)== |

### Graft-versus-host disease (GVHD) :

- Requirements (==Billingham criteria==) : 1. immunocompetent graft (T cells) 2. host antigens recognized as foreign 3. ==immunocompromised host==.
- Settings : ==allogeneic hematopoietic stem cell transplant (most common)==, liver/small bowel transplant, ==transfusion of non-irradiated blood== to immunodeficient recipients.
- Acute GVHD (< 100 days) : ==skin (rash), liver (jaundice — bile duct damage), GIT (bloody diarrhea)== — epithelial cell apoptosis.
- Chronic GVHD : scleroderma-like skin, sicca, obliterative bronchiolitis.
- Prevention : ==irradiation / leukoreduction of blood products==, T-cell depletion.

:::green
- ==Most immunogenic graft : bone marrow > skin > ...==; ==cornea — immunologically privileged (avascular)==.
- Order of importance in HLA matching (kidney) : ==HLA-DR > B > A==.
- ==C4d== — marker of antibody-mediated rejection.
- ==CMV== is the most common opportunistic infection after solid organ transplant; ==EBV → PTLD==.
- ==Graft-versus-leukemia effect== — beneficial T-cell action in allogeneic HSCT.
:::

## Secondary Immunodeficiency & HIV / AIDS

### Causes of secondary immunodeficiency :

1. ==HIV infection== (most important)
2. Malnutrition (most common worldwide), aging
3. ==Malignancy== — leukemia, lymphoma (Hodgkin — T-cell defect), myeloma
4. ==Drugs== — corticosteroids, chemotherapy, immunosuppressants, biologics (anti-TNF)
5. Diabetes mellitus, chronic renal failure, cirrhosis
6. ==Splenectomy== — encapsulated organisms (==OPSI==)
7. Protein loss — nephrotic syndrome, protein-losing enteropathy, burns

### HIV — virology :

- ==Retrovirus (Lentivirus)==; HIV-1 (worldwide; group M — subtype ==C most common in India==), HIV-2 (West Africa).
- Genes : ==gag== (p24 capsid, p17 matrix), ==pol== (reverse transcriptase, integrase, protease), ==env== (==gp120== — binds CD4; ==gp41== — fusion). Regulatory : ==tat==, rev, ==nef== (↓ CD4 and MHC-I), vif, vpr, vpu.
- Receptor : ==CD4== + co-receptor ==CCR5 (macrophage-tropic, R5 — early, transmission)== or ==CXCR4 (T-tropic, X4 — late)==. ==CCR5 Δ32 homozygous → resistance==.

### Transmission :

1. ==Sexual contact (most common worldwide)== — heterosexual in India
2. ==Parenteral== — IV drug users (needle sharing), blood transfusion (risk ~90–95% per unit — highest per-exposure), hemophiliacs (factor concentrates)
3. ==Mother-to-child (vertical)== — ==intrapartum (most common)==, transplacental, breast milk
4. Occupational — ==needle-stick injury (~0.3%)==; mucous membrane (0.09%)

### Natural history :

:::flow
==Acute (primary) HIV syndrome== : 3–6 weeks — fever, sore throat, lymphadenopathy, rash; ==high viremia, ↓ CD4==; seroconversion
==Chronic (clinical latency) phase== : 7–10 years; ==persistent generalized lymphadenopathy==; virus replicates in ==lymphoid tissue (follicular dendritic cells)==; slow CD4 decline
==AIDS== : ==CD4 < 200/µL== or AIDS-defining illness — opportunistic infections, tumours, wasting, encephalopathy
:::

### Lab diagnosis :

1. ==ELISA (4th gen : p24 antigen + antibody)== — screening; window shortened to ==~2–3 weeks==
2. ==Rapid tests== (3 different antigen principles — NACO strategy III)
3. ==Western blot== (confirmatory, historical) — p24 + gp41 + gp120/160
4. ==HIV RNA PCR (viral load)== — ==most sensitive; diagnosis in infants < 18 months (DNA PCR)==, monitoring therapy
5. ==p24 antigen== — earliest marker (before antibodies)
6. ==CD4 count== — staging, prophylaxis (==Pneumocystis prophylaxis at CD4 < 200==)

### Opportunistic infections by CD4 count :

| CD4/µL | Infections |
|---|---|
| < 500 | ==Tuberculosis (any CD4 — most common OI in India)==, oral candidiasis, herpes zoster, Kaposi sarcoma, oral hairy leukoplakia (EBV) |
| ==< 200== | ==Pneumocystis jirovecii pneumonia==, HIV encephalopathy, histoplasmosis, coccidioidomycosis |
| ==< 100== | ==Toxoplasma encephalitis (ring-enhancing lesions)==, ==Cryptococcal meningitis==, esophageal candidiasis, cryptosporidiosis, ==PML (JC virus)==, primary CNS lymphoma (EBV) |
| ==< 50== | ==CMV retinitis==, ==Mycobacterium avium complex (MAC)==, bacillary angiomatosis |

### HIV-associated neoplasms :

1. ==Kaposi sarcoma (HHV-8)== — most common in untreated
2. ==B-cell lymphomas== — DLBCL, ==Burkitt==, ==primary CNS lymphoma (EBV)==, ==primary effusion lymphoma (HHV-8)==, plasmablastic lymphoma
3. ==Invasive cervical carcinoma (HPV)== — AIDS-defining
4. Anal carcinoma (HPV)

### Morphology :

- Lymph nodes : ==follicular hyperplasia (early)== → ==follicular involution / "burnt-out" lymphocyte depletion (late)==.
- CNS : ==microglial nodules, multinucleated giant cells (HIV encephalitis)==; vacuolar myelopathy; ==HIV-associated neurocognitive disorder==.

:::green Handling of infected material & universal precautions
- Treat ==all specimens as potentially infectious== (standard precautions); gloves, gown, mask, eye shield.
- Sharps in ==puncture-proof containers==; ==never recap needles==.
- Disinfection : ==1% sodium hypochlorite (spills, 10,000 ppm with organic matter)==, 2% glutaraldehyde, 70% alcohol; ==autoclaving== for reusable instruments; HIV is heat-labile (56 °C for 30 min).
- Biomedical waste (India, 2016 rules) : ==yellow== — anatomical, soiled; ==red== — contaminated recyclable plastics; ==white (translucent)== — sharps; ==blue== — glassware.
- ==Post-exposure prophylaxis (PEP)== : start ==within 2 h (ideally), up to 72 h==; ==TDF + 3TC + DTG for 28 days==; test at baseline, 6 weeks, 3 months, 6 months.
- Health education : condoms, safe blood (screening all units for HIV, HBV, HCV, syphilis, malaria), harm reduction for IDUs, ==PPTCT — lifelong ART for pregnant women + infant nevirapine prophylaxis==.
:::
