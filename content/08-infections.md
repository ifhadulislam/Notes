# Infectious Diseases

## Patterns of Tissue Response to Infection

| Pattern | Features | Examples |
|---|---|---|
| ==Suppurative (purulent)== | Neutrophils, pus, abscess | ==Pyogenic bacteria== — S. aureus, Streptococci, Gram-negative rods |
| ==Mononuclear / granulomatous== | Lymphocytes, plasma cells, macrophages, granulomas | Viruses, ==intracellular bacteria (TB)==, spirochetes, fungi, helminths |
| ==Cytopathic–cytoproliferative== | Cell necrosis / proliferation, ==inclusion bodies==, multinucleated cells | ==Viruses== — herpes, CMV, HPV (koilocytes), adenovirus |
| ==Tissue necrosis== | Rapid, severe necrosis | ==Clostridium perfringens==, ==Entamoeba histolytica==, HSV encephalitis (temporal lobes) |
| ==Chronic inflammation & scarring== | Fibrosis | ==HBV (cirrhosis)==, ==Schistosoma (pipe-stem fibrosis)== |
| No reaction | Immunosuppression | PCP, MAC in AIDS |

## Tuberculosis

- ==Mycobacterium tuberculosis== — slender, ==acid-fast (mycolic acid)==, aerobic, ==cord factor (trehalose dimycolate)== — virulence, serpentine cords; ==sulfatides== prevent phagolysosome fusion; ==lipoarabinomannan (LAM)== — inhibits macrophage activation.
- India : ==highest burden worldwide== (~27% global cases).

### Pathogenesis (immunity & hypersensitivity) :

:::flow
Inhaled bacilli → ==alveolar macrophages== → bacilli multiply (block phagolysosome maturation — ==ESX-1 secretion system==)
Week 3 : macrophages present antigen (MHC II) + ==IL-12== → ==Th1 cells== → ==IFN-γ==
IFN-γ → macrophage activation : ==NO (iNOS)==, ROS, autophagy, ==defensins (cathelicidin — vitamin D dependent)==
==TNF== → granuloma formation (epithelioid cells, Langhans giant cells) + ==caseous necrosis (hypersensitivity)==
Containment (latent TB) — ==positive tuberculin test== || Failure (HIV, ↓ IFN-γ / IL-12 pathway, anti-TNF) → progressive disease
:::

:::green Genetic susceptibility
- ==Mendelian susceptibility to mycobacterial disease (MSMD)== : ==IFN-γ receptor, IL-12/IL-12R, STAT1== defects → disseminated BCG / NTM.
- ==NRAMP1 (SLC11A1)== polymorphisms; ==vitamin D receptor== polymorphisms.
:::

### Primary vs secondary TB :

| Feature | ==Primary TB== | ==Secondary (post-primary / reactivation) TB== |
|---|---|---|
| Host | Unsensitized (first exposure), children | ==Previously sensitized== |
| Site | ==Ghon focus : lower part of upper lobe / upper part of lower lobe (subpleural)== | ==Apex of upper lobes (Simon / Assmann focus) — high O₂ tension== |
| Lymph nodes | ==Hilar lymphadenopathy== prominent | Minimal |
| Lesion | ==Ghon complex = Ghon focus + hilar node==; calcified = ==Ranke complex== | ==Cavitation== (caseous necrosis erodes into bronchus) |
| Course | 95% heal (fibrocalcification); progressive primary TB in immunocompromised | Cavitary, fibrocaseous; spread |

### Complications / patterns of progression :

1. ==Progressive pulmonary TB== — apical cavities, ==fibrocaseous TB==
2. ==Tuberculous bronchopneumonia (galloping consumption)==
3. ==Miliary TB== — hematogenous (pulmonary vein → systemic : liver, bone marrow, spleen, adrenals, meninges, kidneys, fallopian tubes, epididymis); millet-seed 2 mm lesions; ==choroid tubercles== on fundoscopy
4. ==Isolated organ TB== — meninges, kidneys, adrenals (==Addison disease==), bones (==Pott disease — spine, thoracolumbar==), fallopian tubes (==tubal infertility==)
5. ==Lymphadenitis (scrofula)== — ==most common extrapulmonary TB==; cervical nodes; ==collar-stud abscess==
6. ==Intestinal TB== — ileocecal; ==transverse (girdle) ulcers==, strictures
7. ==Pleural== — effusion (exudate, ==lymphocytic, ↑ ADA > 40 U/L==), empyema, ==tuberculous pleuritis==
8. Laryngitis, ==Rasmussen aneurysm== (pulmonary artery in cavity wall → massive hemoptysis), ==aspergilloma== in old cavity, ==amyloidosis== (AA)

### Diagnosis :

1. ==Sputum smear (ZN)== — needs ==10⁴ bacilli/mL==
2. Culture — ==Löwenstein–Jensen (gold standard, 4–8 weeks)==, ==MGIT (liquid, faster)==
3. ==CBNAAT / GeneXpert MTB/RIF== — ==rpoB== mutation (rifampicin resistance); ==2 h==; Truenat (India)
4. ==Tuberculin skin test (Mantoux, 5 TU PPD)== — type IV; read at ==48–72 h==; ≥ 10 mm positive (≥ 5 mm in HIV)
5. ==IGRA (QuantiFERON-TB Gold)== — ESAT-6, CFP-10 (==not in BCG== — not affected by BCG vaccination)
6. Histopathology — caseating granulomas; ==LAM urine test== (HIV)

:::pearl
- ==False negative Mantoux== : HIV / immunosuppression, ==sarcoidosis==, measles, Hodgkin lymphoma, malnutrition, miliary TB (overwhelming).
- ==Lupus vulgaris== — cutaneous TB (apple-jelly nodules on diascopy); ==scrofuloderma==, ==erythema induratum (Bazin)== — tuberculid.
- ==Atypical (NTM) mycobacteria== : ==M. avium-intracellulare (AIDS)==, ==M. kansasii== (lung), ==M. marinum (fish tank granuloma)==, ==M. ulcerans (Buruli ulcer)==, M. fortuitum/chelonae (post-surgical).
:::

## Leprosy (Hansen Disease)

- ==Mycobacterium leprae== — weakly acid-fast (==5% H₂SO₄ decolorization==); ==grows at low temperature (30–33 °C)== → skin, peripheral nerves, nose, testes, anterior eye; ==cannot be cultured in vitro== (==armadillo, mouse footpad==); ==globi== = clumps of bacilli in macrophages.
- Spread : ==respiratory droplets (nasal secretions)== — most important.

| Feature | ==Tuberculoid (TT)== | ==Lepromatous (LL)== |
|---|---|---|
| Immune response | ==Strong Th1 (IFN-γ, IL-2)== | ==Th2 (IL-4, IL-10)== — weak CMI, ↑ antibodies |
| Lesions | Few, well-defined, hypopigmented, ==anaesthetic== macules | Multiple, symmetric nodules, ==leonine facies==, ==madarosis== (eyebrow loss), saddle nose |
| Nerves | ==Early asymmetric nerve involvement (thickened)== | Late, symmetric glove-and-stocking |
| Histology | ==Well-formed non-caseating granulomas==, nerve destruction; few/no bacilli | ==Foamy macrophages (lepra / Virchow cells)== packed with bacilli (==globi==); ==Grenz zone (clear subepidermal zone)== |
| ==Lepromin test== | ==Positive== | ==Negative== |
| Bacillary index | 0 | ==5–6+== |

- ==Ridley–Jopling classification== : TT – BT – BB – BL – LL (+ indeterminate).
- ==Lepra reactions== : ==Type 1 (reversal reaction — type IV)== — in borderline; ==Type 2 — erythema nodosum leprosum (ENL)== — ==immune complex (type III)== in LL/BL; treat with ==thalidomide==.
- ==Lucio phenomenon== — diffuse LL, necrotizing vasculitis.

## Bacterial Infections

### Pyogenic infections :

| Organism | Lesions |
|---|---|
| ==Staphylococcus aureus== | ==Abscesses, furuncle, carbuncle==, impetigo, osteomyelitis, ==acute IE (normal valves, IV drug users — tricuspid)==, ==TSS (TSST-1)==, ==scalded skin syndrome (exfoliatin — desmoglein 1)==, food poisoning (enterotoxin B, 1–6 h), necrotizing pneumonia (==PVL==) |
| ==Streptococcus pyogenes== | Pharyngitis, ==cellulitis==, erysipelas, ==necrotizing fasciitis==, ==scarlet fever (erythrogenic toxin)==; sequelae : ==rheumatic fever, PSGN== |
| ==Streptococcus pneumoniae== | ==Lobar pneumonia==, otitis, meningitis (adults) |
| Viridans streptococci | ==Subacute IE (damaged valves)==, dental caries (S. mutans) |

### Typhoid (enteric) fever :

- ==Salmonella Typhi== (and Paratyphi A, B) — fecal–oral; enters via ==M cells of Peyer patches== → ==mononuclear phagocytes== → bacteremia → ==gallbladder (carrier state)==.
- Pathology : ==hyperplasia of Peyer patches== → ==oval ulcers along the long axis of ileum== (vs ==transverse in TB==) → ==perforation (3rd week)==, hemorrhage; ==typhoid nodules== (aggregates of macrophages — liver, spleen, marrow) ; ==Zenker's degeneration of rectus abdominis==; ==rose spots==; relative bradycardia; ==leukopenia==.
- Diagnosis : ==blood culture (1st week — best)==, ==bone marrow culture (most sensitive)==, Widal (2nd week onward), stool/urine culture (3rd–4th week).

:::mnemo Typhoid diagnosis by week — "BASU"
Week 1 ==B==lood culture · Week 2 ==A==ntibodies (Widal) · Week 3 ==S==tool culture · Week 4 ==U==rine culture.
:::

### Diphtheria :

- ==Corynebacterium diphtheriae== — exotoxin (==phage-encoded, tox gene==) — ==ADP-ribosylation of EF-2== → inhibits protein synthesis.
- ==Grey-white pseudomembrane== on tonsils / pharynx / larynx — ==bleeds on removal==; ==bull neck==; toxin → ==myocarditis (most common cause of death)==, polyneuropathy (palatal palsy).
- Lab : ==Albert stain (metachromatic / volutin granules)==, ==Loeffler serum slope==, ==potassium tellurite medium==; toxigenicity — ==Elek test==.

### Syphilis :

- ==Treponema pallidum== — spirochete; ==dark-field microscopy==; silver stain; ==cannot be cultured==.

| Stage | Features | Pathology |
|---|---|---|
| ==Primary== (~3 weeks) | ==Hard (indurated), painless chancre==, regional lymphadenopathy | ==Plasma cell-rich infiltrate==, ==obliterative endarteritis== |
| ==Secondary== (2–10 weeks) | ==Generalized maculopapular rash (palms & soles)==, ==condyloma lata==, mucous patches, lymphadenopathy | Plasma cells, endarteritis; most infectious |
| Latent | Asymptomatic | — |
| ==Tertiary== (5–20 y) | ==Cardiovascular (aortitis → ascending aortic aneurysm, aortic regurgitation)==, ==neurosyphilis== (tabes dorsalis, general paresis, ==Argyll Robertson pupil==), ==gumma== | ==Endarteritis obliterans of vasa vasorum== → =="tree-bark" aorta==; gumma — rubbery necrosis |
| ==Congenital== | Early : ==snuffles, rash, hepatosplenomegaly==; late : ==Hutchinson triad (notched incisors, interstitial keratitis, 8th nerve deafness)==, ==saber shins==, saddle nose, ==mulberry molars== | Diffuse fibrosis (==pneumonia alba==), ==osteochondritis==, periostitis |

- Serology : non-treponemal (==VDRL, RPR== — screening, follow-up; ==biological false positive : SLE, APS, pregnancy, malaria, leprosy, IV drug use==), treponemal (==FTA-ABS, TPHA== — confirmation; remain positive for life).

## Viral Infections

| Virus | Inclusion / histology | Key pathology |
|---|---|---|
| ==Poliovirus== | — | ==Anterior horn cells== → ==asymmetric flaccid paralysis==; ==no sensory loss==; enters via oropharynx/intestine (Peyer patches) |
| ==Herpes simplex (HSV-1, 2)== | ==Cowdry type A (intranuclear) inclusions==; ==multinucleated giant cells (Tzanck smear)== — ==3 Ms : multinucleation, molding, margination of chromatin== | Vesicles, ==temporal lobe hemorrhagic necrotizing encephalitis (HSV-1)==, keratitis, ==neonatal herpes (HSV-2)==; latency in sensory ganglia (trigeminal, sacral) |
| VZV | Cowdry A, Tzanck + | Chickenpox; ==shingles (dermatomal)==, latency in dorsal root ganglia |
| ==CMV== | =="Owl-eye" intranuclear inclusion + cytoplasmic inclusions==; ==cytomegaly== | ==Most common congenital infection== (periventricular calcification, deafness); retinitis, colitis, pneumonitis in AIDS / transplant |
| ==EBV== | — | Infectious mononucleosis : ==atypical lymphocytes (Downey cells — reactive CD8 T cells)==, ==heterophile antibody (Paul–Bunnell, Monospot)==; ==splenic rupture==; ampicillin rash |
| ==Rabies== | ==Negri bodies== — eosinophilic cytoplasmic inclusions in ==Purkinje cells (cerebellum)== and ==pyramidal cells of hippocampus (Ammon horn)== | Travels ==retrograde along nerves==; encephalitis (furious — hydrophobia; paralytic) ; ==Babes nodules== |
| ==Measles (rubeola)== | ==Warthin–Finkeldey giant cells== (lymphoid tissue), ==Koplik spots== (buccal mucosa) | Pneumonia (==giant cell pneumonia==), ==SSPE== (years later), ==immune amnesia==; vitamin A ↓ mortality |
| HPV | ==Koilocytes== (perinuclear halo, raisinoid nucleus) | Warts, ==CIN, cervical carcinoma== |
| Adenovirus | ==Smudge cells== (intranuclear) | Pharyngoconjunctival fever, hemorrhagic cystitis |
| ==Molluscum contagiosum== | ==Molluscum (Henderson–Patterson) bodies== — large eosinophilic cytoplasmic | Umbilicated papules |
| Parvovirus B19 | ==Giant pronormoblasts with glassy intranuclear inclusions== | ==Aplastic crisis== (sickle cell, HS), ==hydrops fetalis==, erythema infectiosum ("slapped cheek") |
| HBV | ==Ground-glass hepatocytes== (HBsAg) | Hepatitis, cirrhosis, HCC |
| Smallpox / vaccinia | ==Guarnieri bodies== (cytoplasmic) | — |

:::pearl
- ==Intranuclear inclusions== : herpes (HSV, VZV, CMV), adenovirus, parvovirus, polyoma (JC — PML, ==oligodendrocytes==), measles (both).
- ==Cytoplasmic inclusions== : ==rabies (Negri), poxviruses (Guarnieri, molluscum), CMV (also), measles, RSV==.
- ==Both nuclear + cytoplasmic== : ==CMV, measles==.
:::
